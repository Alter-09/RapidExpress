# STREAM API Y EXPRESIONES LAMBDA

La Stream API (Java 8+) permite procesar colecciones de datos de forma declarativa, encadenando operaciones como filtrar, transformar y recolectar resultados. Las expresiones lambda (`->`) son funciones anónimas que se pasan como parámetro, usadas frecuentemente con Streams.

## Expresiones Lambda

Una lambda es una función sin nombre. Se usa cuando necesitas pasar un comportamiento como argumento (ej. en `filter`, `Comparator`, `Runnable`).

```java
// Sintaxis
(parametros) -> { cuerpo }

// Si es una sola expresión, no necesitas llaves ni return
(parametros) -> expresion

// Ejemplos
(a, b) -> a + b                       // suma dos valores
(String s) -> s.length()              // devuelve la longitud
() -> System.out.println("Hola")      // sin parámetros
```

## Method Reference (Referencia a método)

```java
// En lugar de una lambda que solo llama a un método existente
Comparator.comparing(e -> e.getNombre())

// Se puede usar una referencia al método con ::
Comparator.comparing(Estudiante::getNombre)
```

## Stream API: Operaciones básicas

```java
import java.util.stream.Collectors;

List<Elemento> lista = new ArrayList<>();

// Flujo básico: lista.stream() → operaciones intermedias → operación terminal
lista.stream()
     .filter(e -> condición)       // filtra elementos
     .map(e -> transformación)     // transforma cada elemento
     .collect(Collectors.toList()) // recolecta el resultado en una nueva lista
```

## stream().filter().findFirst().orElse()

Buscar un único elemento que cumpla una condición. Si no lo encuentra, devuelve un valor por defecto.

```java
// Buscar un aeropuerto por código
public Aeropuerto buscarAeropuerto(String codigo) {
    return aeropuertos.obtenerTodos().stream()
            .filter(a -> a.getCodigo().equalsIgnoreCase(codigo)) // filtra por condición
            .findFirst()    // toma el primer resultado (devuelve Optional)
            .orElse(null);  // si no hay resultado, devuelve null
}

// Buscar un pasajero por documento
public Pasajero buscarPasajero(String documento) {
    return pasajeros.obtenerTodos().stream()
            .filter(p -> p.getDocumento().equals(documento))
            .findFirst()
            .orElse(null);
}
```

## stream().filter().collect()

Filtrar múltiples elementos y recolectarlos en una nueva lista.

```java
// Buscar todos los vuelos que van a una ciudad
public List<Vuelo> buscarVuelosPorDestino(String ciudad) {
    String ciudadLower = ciudad.trim().toLowerCase();
    return vuelos.obtenerTodos().stream()
            .filter(v -> v.getDestino().getCiudad().toLowerCase().contains(ciudadLower))
            .collect(Collectors.toList()); // recolecta en una nueva List
}

// Buscar vuelos por ruta (origen y destino)
public List<Vuelo> buscarVuelosPorRuta(String ciudadOrigen, String ciudadDestino) {
    String origenLower = ciudadOrigen.trim().toLowerCase();
    String destinoLower = ciudadDestino.trim().toLowerCase();
    return vuelos.obtenerTodos().stream()
            .filter(v -> v.getOrigen().getCiudad().toLowerCase().contains(origenLower)
                    && v.getDestino().getCiudad().toLowerCase().contains(destinoLower))
            .collect(Collectors.toList());
}
```

## Lambdas con Comparator

```java
import java.util.Comparator;

// Ordenar un TreeSet por nombre usando lambda + method reference
Set<Estudiante> estudiantes = new TreeSet<>(Comparator.comparing(Estudiante::getNombre));
```

## Lambdas con Threads

```java
// Crear un hilo con lambda (en lugar de crear una clase que implemente Runnable)
Thread puerta1 = new Thread(() -> {
    while (eventoAbierto) {
        registrarPersona();
    }
});
puerta1.start();
```

## Resumen de operaciones Stream

| Operación | Tipo | Qué hace |
|---|---|---|
| `filter(condición)` | Intermedia | Filtra elementos que cumplen la condición |
| `map(transformación)` | Intermedia | Transforma cada elemento |
| `findFirst()` | Terminal | Devuelve el primer elemento (como `Optional`) |
| `collect(Collectors.toList())` | Terminal | Recolecta los resultados en una nueva `List` |
| `orElse(valor)` | En Optional | Devuelve un valor por defecto si no hay resultado |

- Los Streams **no modifican** la colección original, crean una nueva.
- Las operaciones intermedias son **lazy** (no se ejecutan hasta que hay una operación terminal).
- Las lambdas reemplazan clases anónimas, haciendo el código más conciso y legible.
