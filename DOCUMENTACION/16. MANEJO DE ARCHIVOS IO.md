# MANEJO DE ARCHIVOS IO

Java proporciona clases en `java.io` para leer y escribir archivos. Las dos formas principales usadas en los proyectos son: archivos de texto (usando `BufferedReader`/`BufferedWriter`) y archivos binarios (usando `ObjectInputStream`/`ObjectOutputStream` con serialización).

## Try-with-resources

La sintaxis `try (recurso)` cierra automáticamente el recurso al finalizar, sin necesidad de un `finally`. Es la forma recomendada para manejar archivos.

```java
// Sintaxis: el recurso se declara dentro del paréntesis del try
try (TipoRecurso recurso = new TipoRecurso()) {
    // usar el recurso
} catch (IOException e) {
    System.out.println("Error: " + e.getMessage());
}
// El recurso se cierra automáticamente aquí
```

## Escribir archivos de texto (BufferedWriter)

```java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

// Escribir texto a un archivo
try (BufferedWriter writer = new BufferedWriter(new FileWriter(ruta))) {
    writer.write("Línea de texto");
    writer.newLine(); // salto de línea
    writer.write("Otra línea");
    System.out.println("Archivo guardado exitosamente");
} catch (IOException e) {
    System.out.println("Error guardando archivo: " + e.getMessage());
}
```

## Leer archivos de texto (BufferedReader)

```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

// Leer un archivo línea por línea
try (BufferedReader reader = new BufferedReader(new FileReader(ruta))) {
    String linea;
    while ((linea = reader.readLine()) != null) {
        linea = linea.trim();
        System.out.println(linea);
    }
} catch (IOException e) {
    System.out.println("Error leyendo archivo: " + e.getMessage());
}
```

## Ejemplo: Guardar datos como JSON manualmente

```java
public static void guardar(List<Producto> productos, String ruta) {
    try (BufferedWriter writer = new BufferedWriter(new FileWriter(ruta))) {
        writer.write("[");
        writer.newLine();

        for (int i = 0; i < productos.size(); i++) {
            Producto producto = productos.get(i);
            writer.write("{");
            writer.newLine();
            writer.write(" \"nombre\" : \"" + producto.getNombre() + "\",");
            writer.newLine();
            writer.write(" \"precio\" :" + producto.getPrecio() + ",");
            writer.newLine();
            writer.write(" \"stock\" :" + producto.getStock());
            writer.newLine();
            writer.write("}");
            if (i < productos.size() - 1) {
                writer.write(",");
            }
        }
        writer.write("]");
        System.out.println("JSON guardado exitosamente");
    } catch (IOException e) {
        System.out.println("Error guardando JSON: " + e.getMessage());
    }
}
```

## Serialización: Guardar objetos en archivos binarios (.dat)

La serialización permite guardar objetos Java directamente en un archivo binario. La clase debe implementar `Serializable`.

```java
import java.io.Serializable;

// 1. La clase debe implementar Serializable
public class Producto implements Serializable {
    private String nombre;
    private double precio;
    private int stock;
    // constructor, getters...
}
```

```java
import java.io.FileOutputStream;
import java.io.ObjectOutputStream;
import java.io.FileInputStream;
import java.io.ObjectInputStream;

// 2. Guardar objetos en archivo .dat
public static void guardar(List<Producto> productos, String ruta) {
    try (FileOutputStream archivo = new FileOutputStream(ruta);
         ObjectOutputStream salida = new ObjectOutputStream(archivo)) {
        salida.writeObject(productos); // guarda toda la lista como objeto
        System.out.println("DAT guardado correctamente");
    } catch (IOException e) {
        System.out.println("Error guardando DAT: " + e.getMessage());
    }
}

// 3. Leer objetos desde archivo .dat
@SuppressWarnings("unchecked")
public static List<Producto> cargar(String ruta) {
    try (FileInputStream archivo = new FileInputStream(ruta);
         ObjectInputStream entrada = new ObjectInputStream(archivo)) {
        return (List<Producto>) entrada.readObject(); // lee y castea el objeto
    } catch (IOException | ClassNotFoundException e) {
        System.out.println("Error al leer el archivo DAT: " + e.getMessage());
        return new ArrayList<>(); // retorna lista vacía si falla
    }
}
```

## Resumen de clases de I/O

| Clase | Uso |
|---|---|
| `FileWriter` / `FileReader` | Escritura/lectura de archivos de texto (caracteres) |
| `BufferedWriter` / `BufferedReader` | Escritura/lectura con buffer (más eficiente) |
| `FileOutputStream` / `FileInputStream` | Escritura/lectura de archivos binarios (bytes) |
| `ObjectOutputStream` / `ObjectInputStream` | Serialización/deserialización de objetos |

- Siempre usa **try-with-resources** para cerrar archivos automáticamente.
- `BufferedWriter`/`BufferedReader` envuelven a `FileWriter`/`FileReader` para mejorar rendimiento.
- Para serializar, la clase **debe** implementar `Serializable`.
- `@SuppressWarnings("unchecked")` se usa al hacer casting de objetos genéricos deserializados.
