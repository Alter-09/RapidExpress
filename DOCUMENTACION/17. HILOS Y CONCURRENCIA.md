# HILOS Y CONCURRENCIA

Los hilos (`Thread`) permiten ejecutar múltiples tareas en paralelo dentro de un mismo programa. Java proporciona la clase `Thread`, la interfaz `Runnable` y herramientas de sincronización para gestionar la concurrencia de forma segura.

## Crear un hilo con Runnable

La interfaz `Runnable` define una tarea que puede ejecutarse en un hilo. Se implementa el método `run()` con la lógica de la tarea.

```java
// Implementar Runnable en una clase
public class TareaCajero implements Runnable {
    private final int[] carritoCliente;

    public TareaCajero(int[] carritoCliente) {
        this.carritoCliente = carritoCliente;
    }

    @Override
    public void run() {
        String nombreCajero = Thread.currentThread().getName(); // nombre del hilo actual
        System.out.println(nombreCajero + " ha empezado a procesar");

        for (int i = 0; i < carritoCliente.length; i++) {
            int tiempoDeProcesado = carritoCliente[i];
            try {
                Thread.sleep(tiempoDeProcesado); // simula trabajo (pausa el hilo)
            } catch (InterruptedException e) {
                System.out.println(nombreCajero + " fue interrumpido");
                Thread.currentThread().interrupt(); // limpia la bandera de interrupción
            }
        }
    }
}
```

## Crear y lanzar hilos con lambda

```java
// Crear hilos con expresiones lambda (sin necesidad de una clase separada)
Thread puerta1 = new Thread(() -> {
    while (eventoAbierto) {
        registrarPersona();
    }
});

Thread puerta2 = new Thread(() -> {
    while (eventoAbierto) {
        registrarPersona();
    }
});

// Iniciar los hilos (se ejecutan en paralelo)
puerta1.start();
puerta2.start();
```

## Métodos principales de Thread

```java
thread.start();   // inicia la ejecución del hilo en paralelo
thread.join();     // espera a que el hilo termine antes de continuar
Thread.sleep(ms);  // pausa el hilo actual por N milisegundos

// Ejemplo: esperar a que ambos hilos terminen
puerta1.start();
puerta2.start();

Thread.sleep(3000);     // esperar 3 segundos
eventoAbierto = false;  // señal para que los hilos paren

puerta1.join(); // espera a que puerta1 termine
puerta2.join(); // espera a que puerta2 termine

System.out.println("Personas registradas: " + contador.get());
```

## synchronized (sincronización)

Cuando múltiples hilos acceden a un recurso compartido, pueden ocurrir condiciones de carrera. La palabra `synchronized` asegura que solo un hilo a la vez ejecute un bloque de código.

```java
// Método sincronizado: solo un hilo puede ejecutar este método a la vez
static synchronized void registrarPersona() {
    contador.incrementAndGet();
}

// Bloque sincronizado: se usa un objeto como "candado"
static final Object lock = new Object();

void metodo() {
    synchronized (lock) {
        // solo un hilo a la vez entra aquí
    }
}
```

## volatile

La palabra `volatile` asegura que todos los hilos vean el valor más reciente de una variable compartida (evita que cada hilo cache su propia copia).

```java
// Sin volatile, un hilo podría no ver el cambio hecho por otro hilo
static volatile boolean eventoAbierto = true;

// Un hilo cambia el valor
eventoAbierto = false; // todos los hilos ven este cambio inmediatamente
```

## AtomicInteger

`AtomicInteger` es una clase que permite operaciones atómicas (thread-safe) sobre un entero sin necesidad de `synchronized`.

```java
import java.util.concurrent.atomic.AtomicInteger;

static AtomicInteger contador = new AtomicInteger(0);

// Incrementar de forma segura (atómica)
contador.incrementAndGet(); // equivale a contador++ pero thread-safe

// Obtener el valor
int valor = contador.get();
```

## Ejemplo completo: Simulación de evento con hilos

```java
public class Sincronizacion {
    static AtomicInteger contador = new AtomicInteger(0);
    static volatile boolean eventoAbierto = true;

    static synchronized void registrarPersona() {
        contador.incrementAndGet();
    }

    public static void main(String[] args) throws InterruptedException {
        Thread puerta1 = new Thread(() -> {
            while (eventoAbierto) {
                registrarPersona();
            }
        });
        Thread puerta2 = new Thread(() -> {
            while (eventoAbierto) {
                registrarPersona();
            }
        });

        puerta1.start();
        puerta2.start();

        Thread.sleep(3000);      // el evento dura 3 segundos
        eventoAbierto = false;   // cierra las puertas

        puerta1.join();
        puerta2.join();

        System.out.println("Personas registradas: " + contador.get());
    }
}
```

- `Runnable` → interfaz para definir la tarea de un hilo (método `run()`).
- `Thread` → clase para crear y gestionar hilos (`start()`, `join()`, `sleep()`).
- `synchronized` → garantiza acceso exclusivo a un recurso compartido.
- `volatile` → garantiza visibilidad de cambios entre hilos.
- `AtomicInteger` → operaciones numéricas thread-safe sin `synchronized`.
- Siempre maneja `InterruptedException` dentro de `Thread.sleep()`.
