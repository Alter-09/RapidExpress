# CLASES ABSTRACTAS

Una clase abstracta es una clase que no se puede instanciar directamente (no puedes hacer `new ClaseAbstracta()`). Sirve como plantilla o contrato parcial para que otras clases la hereden. Puede contener métodos abstractos (sin cuerpo, que las hijas deben implementar) y métodos concretos (con cuerpo, que las hijas heredan directamente).

## Sintaxis

```java
// Declarar una clase abstracta
public abstract class NombreClase {
    // Atributos normales
    private TipoDato atributo;

    // Constructor (las hijas lo usan con super())
    public NombreClase(TipoDato atributo) {
        this.atributo = atributo;
    }

    // Métodos concretos (con cuerpo, se heredan tal cual)
    public TipoDato getAtributo() {
        return atributo;
    }

    // Métodos abstractos (sin cuerpo, las hijas DEBEN implementarlos)
    public abstract TipoRetorno nombreMetodo();
}
```

## Clase hija que hereda de una abstracta

```java
public class ClaseHija extends ClaseAbstracta {

    public ClaseHija(TipoDato valorPadre) {
        super(valorPadre); // llama al constructor de la clase abstracta
    }

    @Override
    public TipoRetorno nombreMetodo() {
        // OBLIGATORIO: implementar el método abstracto
        return valor;
    }
}
```

## Ejemplo: Persona abstracta con Pasajero y Piloto

```java
// Clase abstracta (no se puede hacer new Persona())
public abstract class Persona {
    private String documento;
    private String nombre;

    public Persona(String documento, String nombre) {
        this.documento = documento;
        this.nombre = nombre;
    }

    public String getDocumento() { return documento; }
    public String getNombre() { return nombre; }

    // Cada tipo de persona describe diferente
    public abstract String obtenerDescripcion();
}

// =====================================================================//

// Clase concreta: Pasajero
public class Pasajero extends Persona {
    private int edad;

    public Pasajero(String documento, String nombre, int edad) {
        super(documento, nombre); // llama al constructor de Persona
        this.edad = edad;
    }

    @Override
    public String obtenerDescripcion() {
        return "Pasajero: " + getNombre();
    }
}

// =====================================================================//

// Clase concreta: Piloto
public class Piloto extends Persona {
    private String licencia;
    private int horasVuelo;

    public Piloto(String documento, String nombre, String licencia, int horasVuelo) {
        super(documento, nombre);
        this.licencia = licencia;
        this.horasVuelo = horasVuelo;
    }

    @Override
    public String obtenerDescripcion() {
        return "Piloto: " + getNombre() + " - Licencia: " + licencia;
    }
}
```

## Ejemplo: Cuenta abstracta con CuentaBancaria

```java
abstract class Cuenta {
    protected String titular;
    protected double saldo;

    public Cuenta(String titular, double saldo) {
        this.titular = titular;
        this.saldo = saldo;
    }

    // Métodos abstractos: cada tipo de cuenta implementa su propia lógica
    public abstract void depositar(double monto);
    public abstract void retirar(double monto);
}

// =====================================================================//

public class CuentaBancaria extends Cuenta {
    public CuentaBancaria(String titular, double saldo) {
        super(titular, saldo);
    }

    @Override
    public void depositar(double monto) {
        this.saldo += monto;
    }

    @Override
    public void retirar(double monto) {
        if (monto <= this.saldo) {
            this.saldo -= monto;
        }
    }
}
```

- Una clase abstracta **puede tener** constructor, atributos, métodos concretos Y métodos abstractos.
- Una clase concreta que hereda de una abstracta **debe implementar** todos los métodos abstractos.
- Si una clase hija no implementa todos los métodos abstractos, ella también debe ser declarada `abstract`.
- Usa clases abstractas cuando tienes lógica común que compartir entre clases hijas, pero necesitas que cada hija defina su propio comportamiento para ciertos métodos.
