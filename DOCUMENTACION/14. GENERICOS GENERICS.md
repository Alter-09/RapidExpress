# GENERICOS GENERICS

Los genéricos (`Generics`) permiten crear clases, interfaces y métodos que trabajan con cualquier tipo de dato sin perder la seguridad de tipos. En lugar de escribir una clase separada para cada tipo (una para `Aeropuerto`, otra para `Pasajero`, otra para `Vuelo`), se usa un parámetro de tipo `<T>` que se reemplaza por el tipo real al momento de usar la clase.

## Sintaxis

```java
// Clase genérica: <T> es el parámetro de tipo (puede ser cualquier letra, T es convención)
public class NombreClase<T> {
    private T dato;

    public void setDato(T dato) {
        this.dato = dato;
    }

    public T getDato() {
        return dato;
    }
}

// Usar la clase genérica con un tipo concreto
NombreClase<String> textos = new NombreClase<>();
NombreClase<Integer> numeros = new NombreClase<>();
```

## Ejemplo: Repositorio genérico

```java
// Una sola clase Repositorio sirve para cualquier tipo de objeto
public class Repositorio<T> {
    private List<T> elementos = new ArrayList<>();

    public void agregar(T elemento) {
        elementos.add(elemento);
    }

    public List<T> obtenerTodos() {
        return new ArrayList<>(elementos); // devuelve copia defensiva
    }

    public boolean existe(T elemento) {
        return elementos.contains(elemento);
    }

    public int size() {
        return elementos.size();
    }

    public void limpiar() {
        elementos.clear();
    }
}
```

```java
// Uso del Repositorio genérico con diferentes tipos
Repositorio<Aeropuerto> aeropuertos = new Repositorio<>(); // T = Aeropuerto
Repositorio<Pasajero> pasajeros = new Repositorio<>();     // T = Pasajero
Repositorio<Vuelo> vuelos = new Repositorio<>();           // T = Vuelo

// Agregar elementos (el tipo es seguro, no puedes agregar un Pasajero al de Aeropuerto)
aeropuertos.agregar(new Aeropuerto("BOG", "El Dorado", "Bogotá", "Colombia"));
pasajeros.agregar(new Pasajero("1001", "Laura Gómez", 25));

// Obtener todos
List<Aeropuerto> todosAeropuertos = aeropuertos.obtenerTodos();
List<Pasajero> todosPasajeros = pasajeros.obtenerTodos();

// Consultar tamaño
System.out.println("Aeropuertos registrados: " + aeropuertos.size());
System.out.println("Pasajeros registrados: " + pasajeros.size());
```

## Convenciones de nombres para parámetros de tipo

```java
<T> // Type (tipo genérico general)
<E> // Element (elemento de una colección)
<K> // Key (clave de un mapa)
<V> // Value (valor de un mapa)
<N> // Number (tipo numérico)
```

## Las colecciones de Java usan genéricos

```java
// ArrayList es genérica: ArrayList<E>
List<String> nombres = new ArrayList<>();

// HashMap es genérica: HashMap<K, V>
Map<String, Double> notas = new HashMap<>();

// Set es genérica: Set<E>
Set<String> ciudades = new HashSet<>();
```

- Los genéricos evitan el **casting manual** y los errores de tipo en tiempo de ejecución.
- El parámetro de tipo `<T>` se reemplaza por el tipo concreto al crear la instancia.
- No se pueden usar tipos primitivos (`int`, `double`), se usan las clases wrapper (`Integer`, `Double`).
- Una sola clase genérica reemplaza múltiples clases repetitivas (principio DRY: Don't Repeat Yourself).
