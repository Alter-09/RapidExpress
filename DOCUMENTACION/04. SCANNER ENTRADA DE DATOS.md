# SCANNER ENTRADA DE DATOS

La clase `Scanner` permite leer datos de entrada desde la consola (teclado). Es la forma estándar en Java para recibir input del usuario en aplicaciones de consola.

## Importar y crear el Scanner

```java
import java.util.Scanner; // importar el paquete

// Crear el Scanner apuntando a la entrada estándar (teclado)
Scanner scanner = new Scanner(System.in);
// 'new Scanner(System.in)' le indica al programa que la fuente de datos viene de la consola
```

## Métodos de lectura por tipo de dato

```java
Scanner sc = new Scanner(System.in);

// Leer un entero
System.out.print("Ingrese su edad: ");
int edad = sc.nextInt(); // espera un número entero

// Leer un decimal
System.out.print("Ingrese su nota: ");
double nota = sc.nextDouble(); // espera un número decimal

// Leer un booleano
System.out.print("¿Asistió? (true/false): ");
boolean estado = sc.nextBoolean(); // espera true o false

// Leer una línea completa de texto
System.out.print("Ingrese su nombre: ");
String nombre = sc.nextLine(); // lee hasta el salto de línea

// Leer una sola palabra
String palabra = sc.next(); // lee hasta el primer espacio
```

## Problema común: buffer del Scanner

Cuando se usa `nextInt()` o `nextDouble()` antes de `nextLine()`, el salto de línea queda en el buffer y `nextLine()` lo consume vacío. La solución es limpiar el buffer.

```java
Scanner sc = new Scanner(System.in);

System.out.print("Ingrese cantidad: ");
int cantidad = sc.nextInt();

sc.nextLine(); // Limpiar buffer del scanner (IMPORTANTE)

System.out.print("Ingrese nombre: ");
String nombre = sc.nextLine(); // ahora sí captura correctamente
```

## Ejemplo completo: menú interactivo

```java
Scanner scanner = new Scanner(System.in);
boolean continuar = true;

while (continuar) {
    System.out.println("\n=== MENÚ ===");
    System.out.println("1. Registrar");
    System.out.println("2. Consultar");
    System.out.println("3. Salir");
    System.out.print("Opción: ");

    int opcion = scanner.nextInt();
    scanner.nextLine(); // limpiar buffer

    switch (opcion) {
        case 1:
            System.out.print("Nombre: ");
            String nombre = scanner.nextLine();
            // lógica de registro
            break;
        case 2:
            // lógica de consulta
            break;
        case 3:
            continuar = false;
            break;
        default:
            System.out.println("Opción no válida");
    }
}
```

## Cerrar el Scanner

```java
// Es buena práctica cerrar el scanner al finalizar
Scanner sc = new Scanner(System.in);
// ... usar el scanner ...
sc.close(); // libera el recurso
System.out.println("Programa finalizado");
```

- `nextInt()` → captura un `int`
- `nextDouble()` → captura un `double`
- `nextBoolean()` → captura un `boolean`
- `nextLine()` → captura toda la línea como `String`
- `next()` → captura una sola palabra como `String`
- Siempre agrega `sc.nextLine()` después de `nextInt()` o `nextDouble()` si vas a leer texto después.
