# ENUMERACIONES ENUM

Un `enum` (enumeración) es un tipo especial de clase que representa un conjunto fijo de constantes con nombre. Se usa cuando una variable solo puede tomar un valor dentro de un grupo cerrado de opciones (ej. estados, niveles, días de la semana).

## Sintaxis

```java
// Declarar un enum (generalmente en su propio archivo .java)
public enum NombreEnum {
    VALOR_UNO,
    VALOR_DOS,
    VALOR_TRES;
}

// Usar el enum como tipo de dato
NombreEnum variable = NombreEnum.VALOR_UNO;
```

## Ejemplo: Estado de un vuelo

```java
// Declaración del enum
public enum EstadoVuelo {
    PROGRAMADO,
    ABORDANDO,
    EN_VUELO,
    FINALIZADO,
    CANCELADO
}

// =====================================================================//

// Uso en una clase
public class Vuelo {
    private EstadoVuelo estado;

    public Vuelo() {
        this.estado = EstadoVuelo.PROGRAMADO; // valor inicial
    }

    public EstadoVuelo getEstado() {
        return estado;
    }

    public void setEstado(EstadoVuelo estado) {
        this.estado = estado;
    }
}

// Cambiar el estado
vuelo.setEstado(EstadoVuelo.ABORDANDO);
```

## Ejemplo: Nivel de curso

```java
public enum NivelCurso {
    BASICO,
    INTERMEDIO,
    AVANZADO;
}

// =====================================================================//

// Uso en un constructor
public class Estudiante {
    private NivelCurso nivel;

    public Estudiante(String nombre, String id, NivelCurso nivel) {
        this.nivel = nivel;
    }
}

// Crear un estudiante con un nivel
Estudiante e = new Estudiante("Fabio", "123", NivelCurso.BASICO);
```

## Usar enum con switch

```java
// Recorrer todos los valores de un enum con .values()
for (EstadoVuelo e : EstadoVuelo.values()) {
    System.out.println(e);
}

// Usar enum en un switch (Java 14+ con arrow syntax)
switch (vuelo.getEstado()) {
    case PROGRAMADO -> programados++;
    case ABORDANDO -> abordando++;
    case EN_VUELO -> enVuelo++;
    case FINALIZADO -> finalizados++;
    case CANCELADO -> cancelados++;
}
```

## Comparar valores de un enum

```java
// Comparar con == (es seguro y recomendado para enums)
if (vuelo.getEstado() == EstadoVuelo.PROGRAMADO) {
    System.out.println("El vuelo está programado");
}

// También funciona con != 
if (vuelo.getEstado() != EstadoVuelo.CANCELADO) {
    System.out.println("El vuelo no está cancelado");
}
```

- Los enum reemplazan el uso de constantes `int` o `String` sueltas, dando seguridad de tipos.
- `values()` devuelve un arreglo con todos los valores del enum.
- Se comparan con `==` (no con `.equals()`).
- Por convención, los valores del enum se escriben en **MAYÚSCULAS** separadas por **guion bajo** (ej. `EN_VUELO`).
