# CONEXION A BASE DE DATOS JDBC

JDBC (Java Database Connectivity) es la API estándar de Java para conectarse a bases de datos relacionales. Permite ejecutar consultas SQL desde código Java. En los proyectos se usa para conectarse a MySQL.

## Importaciones necesarias

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.Statement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.DatabaseMetaData;
```

## Establecer la conexión

```java
// Datos de conexión
private static String url = "jdbc:mysql://localhost:3306/NombreBD";
private static String user = "root";
private static String password = "miPassword";

// Crear la conexión
public static Connection con = null;

public static Connection MySQLConnection() {
    con = null;
    try {
        con = DriverManager.getConnection(url, user, password);

        if (con != null) {
            DatabaseMetaData meta = con.getMetaData();
            System.out.println("Base de datos conectada: " + meta.getDriverName());
        }
    } catch (SQLException ex) {
        System.out.println("Error al conectar la BD: " + ex.getMessage());
    }
    return con;
}
```

## Estructura de clases para JDBC

```java
// 1. Clase de conexión (maneja solo la conexión)
public abstract class ConexionBD {
    private static String url = "jdbc:mysql://localhost:3306/NombreBD";
    private static String user = "root";
    private static String password = "password";

    public static Connection con = null;

    public static Connection MySQLConnection() {
        try {
            con = DriverManager.getConnection(url, user, password);
        } catch (SQLException ex) {
            System.out.println("Error: " + ex.getMessage());
        }
        return con;
    }
}

// =====================================================================//

// 2. Clase de operaciones (maneja consultas SQL)
public abstract class Operaciones {
    public static Connection con;       // la conexión
    public static Statement stmt = null; // para ejecutar SQL
    public static ResultSet rs = null;   // para leer resultados de SELECT
}
```

## Componentes principales de JDBC

| Componente | Qué hace |
|---|---|
| `DriverManager` | Gestiona los drivers y crea la conexión |
| `Connection` | Representa la conexión activa con la BD |
| `Statement` | Permite ejecutar sentencias SQL |
| `ResultSet` | Almacena los resultados de un `SELECT` |
| `SQLException` | Excepción que se lanza cuando hay errores de BD |
| `DatabaseMetaData` | Información sobre la base de datos (driver, versión, etc.) |

## Formato de la URL de conexión

```java
// MySQL
"jdbc:mysql://host:puerto/nombreBaseDatos"

// Ejemplos
"jdbc:mysql://localhost:3306/MiBD"         // conexión local
"jdbc:mysql://192.168.1.100:3306/MiBD"     // conexión remota
```

## Flujo típico de JDBC

```java
// 1. Establecer conexión
Connection con = ConexionBD.MySQLConnection();

// 2. Crear Statement
Statement stmt = con.createStatement();

// 3. Ejecutar consulta
ResultSet rs = stmt.executeQuery("SELECT * FROM tabla");

// 4. Leer resultados
while (rs.next()) {
    String nombre = rs.getString("columna_nombre");
    int edad = rs.getInt("columna_edad");
    System.out.println(nombre + " - " + edad);
}

// 5. Cerrar recursos (en orden inverso)
rs.close();
stmt.close();
con.close();
```

- La URL sigue el formato `jdbc:motor://host:puerto/baseDatos`.
- Siempre maneja `SQLException` con try-catch al trabajar con BD.
- Es buena práctica separar la lógica de conexión de la lógica de operaciones (en clases diferentes).
- El driver de MySQL (`mysql-connector-java`) debe estar como dependencia en el `pom.xml` del proyecto Maven.
- Cierra los recursos (`Connection`, `Statement`, `ResultSet`) cuando ya no los necesites para evitar fugas de memoria.

## PreparedStatement (Consultas parametrizadas)

`PreparedStatement` es una versión más segura de `Statement`. Usa marcadores `?` en lugar de concatenar valores directamente en el SQL, lo que previene ataques de **SQL Injection**.

```java
import java.sql.PreparedStatement;

// Statement (INSEGURO - vulnerable a SQL Injection)
String sql = "SELECT * FROM usuario WHERE name='" + nombre + "'"; // NO hacer esto

// PreparedStatement (SEGURO - usa marcadores ?)
String sentencia = "SELECT * FROM usuario WHERE name=?";
PreparedStatement ps = con.prepareStatement(sentencia);
ps.setString(1, nombre); // el 1 indica la posición del primer ?
```

```java
// Métodos para asignar valores según el tipo de dato
ps.setString(1, "texto");    // para VARCHAR, TEXT
ps.setInt(2, 42);            // para INT
ps.setDouble(3, 99.99);     // para DOUBLE, DECIMAL
// El número indica la posición del ? (empezando en 1, no en 0)
```

## Clase Operaciones completa

La clase `Operaciones` centraliza todos los métodos genéricos para interactuar con la BD. Es abstracta porque solo contiene métodos estáticos utilitarios.

```java
public abstract class Operaciones {
    public static Connection con;
    public static Statement stmt = null;
    public static ResultSet rs = null;

    // Establecer y obtener la conexión
    public static Connection setConnection(Connection connection) {
        Operaciones.con = connection;
        return connection;
    }
    public static Connection getConnection() {
        return con;
    }

    // Método genérico para SELECT (lectura)
    // executeQuery() devuelve un ResultSet con los datos
    public static ResultSet consultar_BD(PreparedStatement sentencia) {
        try {
            rs = sentencia.executeQuery();
        } catch (SQLException | RuntimeException sqlex) {
            System.out.println("Error al consultar: " + sqlex);
            return null;
        }
        return rs;
    }

    // Método genérico para INSERT, UPDATE, DELETE (escritura)
    // executeUpdate() devuelve el número de filas afectadas
    public static int insertar_actualizar_borrar_BD(PreparedStatement sentencia) {
        int filas; // guarda el numero de filas afectadas
        try {
            filas = sentencia.executeUpdate();
        } catch (SQLException | RuntimeException sqlex) {
            System.out.println("ERROR al modificar: " + sqlex);
            return 0;
        }
        return filas;
    }

    // Cerrar conexión de forma segura
    public static void closeConnection(Connection con) {
        if (con != null) {
            try {
                con.close();
            } catch (SQLException ex) {
                System.out.println("Error al cerrar: " + ex.getMessage());
            }
        }
    }

    public static void cerrarConexion() {
        closeConnection(con);
    }
}
```

- `executeQuery()` → para `SELECT` (devuelve `ResultSet`)
- `executeUpdate()` → para `INSERT`, `UPDATE`, `DELETE` (devuelve `int` con filas afectadas)

## Transacciones (commit y rollback)

Por defecto, cada sentencia SQL se ejecuta y confirma automáticamente (`autoCommit = true`). Con `setAutoCommit(false)` se desactiva esto para agrupar varias operaciones en una transacción: si todo sale bien se confirma con `commit()`, si algo falla se revierte con `rollback()`.

```java
// Desactivar autoCommit para manejar la transacción manualmente
public static boolean SetAutoCommit(boolean parametro) {
    try {
        con.setAutoCommit(parametro);
    } catch (SQLException sqlex) {
        return false;
    }
    return true;
}

// Confirmar todos los cambios de la transacción
public static boolean commitBD() {
    try {
        con.commit();
        return true;
    } catch (SQLException sqlex) {
        return false;
    }
}

// Revertir todos los cambios si algo falló
public static boolean rollbackBD() {
    try {
        con.rollback();
        return true;
    } catch (SQLException sqlex) {
        return false;
    }
}
```

```java
// Patrón de uso: transacción segura
Operaciones.SetAutoCommit(false); // desactiva autocommit

if (Operaciones.insertar_actualizar_borrar_BD(ps) > 0) {
    Operaciones.commitBD();       // todo salió bien → confirmar
} else {
    Operaciones.rollbackBD();     // algo falló → revertir
}
Operaciones.cerrarConexion();     // siempre cerrar al final
```

## Operaciones CRUD completas

CRUD = Create (INSERT), Read (SELECT), Update (UPDATE), Delete (DELETE).

### INSERT (Registrar)

```java
public static boolean registrarUsuario(String nombre) throws SQLException {
    Usuario u = new Usuario(nombre);
    Operaciones.setConnection(ConexionBD.MySQLConnection());

    String sentencia = "INSERT INTO usuario(name) VALUES (?);";
    PreparedStatement ps = Operaciones.getConnection().prepareStatement(sentencia);
    ps.setString(1, u.getName()); // asigna el valor al ?

    if (Operaciones.SetAutoCommit(false)) {
        if (Operaciones.insertar_actualizar_borrar_BD(ps) > 0) {
            Operaciones.commitBD();
            Operaciones.cerrarConexion();
            return true;
        } else {
            Operaciones.rollbackBD();
            Operaciones.cerrarConexion();
            return false;
        }
    } else {
        Operaciones.cerrarConexion();
        return false;
    }
}
```

### SELECT (Consultar)

```java
public static List<Usuario> ConsultarUsuario(String nombre) throws SQLException {
    List<Usuario> user = new ArrayList<>();
    Operaciones.setConnection(ConexionBD.MySQLConnection());

    String sentencia = "SELECT * FROM usuario WHERE name=?";
    PreparedStatement ps = Operaciones.getConnection().prepareStatement(sentencia);
    ps.setString(1, nombre);

    ResultSet rs = Operaciones.consultar_BD(ps);
    while (rs.next()) {
        String name = rs.getString("name");     // obtener por nombre de columna
        int idUser = rs.getInt("idUser");       // obtener por nombre de columna
        Usuario u = new Usuario(idUser, name);
        user.add(u);
    }

    Operaciones.cerrarConexion();
    return user;
}
```

### UPDATE (Actualizar)

```java
public static boolean actualizarUsuario(int id, String nombre) throws SQLException {
    Usuario u = new Usuario(id, nombre);
    Operaciones.setConnection(ConexionBD.MySQLConnection());

    String sentencia = "UPDATE usuario SET name=? WHERE idUser=?";
    PreparedStatement ps = Operaciones.getConnection().prepareStatement(sentencia);
    ps.setString(1, u.getName()); // primer ? → name
    ps.setInt(2, u.getIdUser());  // segundo ? → idUser

    if (Operaciones.SetAutoCommit(false)) {
        if (Operaciones.insertar_actualizar_borrar_BD(ps) > 0) {
            Operaciones.commitBD();
            Operaciones.cerrarConexion();
            return true;
        } else {
            Operaciones.rollbackBD();
            Operaciones.cerrarConexion();
            return false;
        }
    } else {
        Operaciones.cerrarConexion();
        return false;
    }
}
```

### DELETE (Borrar)

```java
public static boolean borrarUsuario(String nombre) throws SQLException {
    Operaciones.setConnection(ConexionBD.MySQLConnection());

    String sentencia = "DELETE FROM usuario WHERE name=?";
    PreparedStatement ps = Operaciones.getConnection().prepareStatement(sentencia);
    ps.setString(1, nombre);

    if (Operaciones.SetAutoCommit(false)) {
        if (Operaciones.insertar_actualizar_borrar_BD(ps) > 0) {
            Operaciones.commitBD();
            Operaciones.cerrarConexion();
            return true;
        } else {
            Operaciones.rollbackBD();
            Operaciones.cerrarConexion();
            return false;
        }
    } else {
        Operaciones.cerrarConexion();
        return false;
    }
}
```

## Clase Modelo (la entidad)

La clase modelo representa la tabla de la base de datos como un objeto Java. Cada atributo corresponde a una columna.

```java
public class Usuario {
    private int idUser;
    private String name;

    // Constructor completo (para leer de la BD)
    public Usuario(int idUser, String name) {
        this.idUser = idUser;
        this.name = name;
    }

    // Constructor sin ID (para insertar, la BD genera el ID)
    public Usuario(String name) {
        this.name = name;
    }

    public int getIdUser() { return idUser; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    @Override
    public String toString() {
        return "Usuario {" + "idUser: " + idUser + " ,name= " + name + "}";
    }
}
```

## Arquitectura MVC para JDBC

El proyecto usa el patrón Modelo-Vista-Controlador para organizar el código de base de datos:

```
proyecto/
├── modelo/
│   ├── clases/
│   │   └── Usuario.java          ← MODELO: la entidad (atributos = columnas)
│   └── persistencia/
│       ├── ConexionBD.java        ← Conexión a la BD (url, user, password)
│       └── Operaciones.java       ← Métodos genéricos (consultar, insertar, commit, rollback)
├── Controlador/
│   └── ControladorUsuario.java    ← CONTROLADOR: lógica CRUD (registrar, consultar, actualizar, borrar)
└── vista/
    └── ConexionDB.java            ← VISTA: el main, llama al controlador
```

```java
// Vista: el punto de entrada (main)
public class ConexionDB {
    public static void main(String[] args) {
        try {
            // Registrar
            boolean registrado = ControladorUsuario.registrarUsuario("sergio");
            System.out.println("Usuario registrado: " + registrado);

            // Consultar
            List<Usuario> users = ControladorUsuario.ConsultarUsuario("sergio");
            for (Usuario user : users) {
                System.out.println(user);
            }

            // Actualizar
            if (!users.isEmpty()) {
                int idUser = users.get(0).getIdUser();
                ControladorUsuario.actualizarUsuario(idUser, "sergio actualizado");
            }
        } catch (SQLException e) {
            System.out.println("Error SQL");
            e.printStackTrace();
        }
    }
}
```

- `PreparedStatement` con `?` es **siempre** más seguro que concatenar strings en el SQL.
- `executeQuery()` → para `SELECT`. `executeUpdate()` → para `INSERT/UPDATE/DELETE`.
- Siempre usa `setAutoCommit(false)` + `commit()`/`rollback()` para operaciones de escritura.
- Separa el código en capas MVC: **Modelo** (entidad + persistencia), **Controlador** (lógica CRUD), **Vista** (main).
- `rs.getString("columna")` y `rs.getInt("columna")` leen datos del `ResultSet` por nombre de columna.
- Siempre cierra la conexión con `cerrarConexion()` al terminar cada operación.
