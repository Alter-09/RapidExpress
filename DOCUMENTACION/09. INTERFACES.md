# INTERFACES

Una interfaz en Java es un contrato que define qué métodos debe tener una clase, pero sin decir cómo implementarlos. A diferencia de una clase abstracta, una interfaz no tiene estado (atributos de instancia) ni constructores. Una clase puede implementar múltiples interfaces (a diferencia de la herencia, que solo permite una clase padre).

## Sintaxis

```java
// Declarar una interfaz
public interface NombreInterfaz {
    // Métodos abstractos (no tienen cuerpo)
    void metodoUno();
    TipoRetorno metodoDos(TipoDato parametro);
}

// Implementar una interfaz en una clase
public class MiClase implements NombreInterfaz {
    @Override
    public void metodoUno() {
        // OBLIGATORIO: implementar el método
    }

    @Override
    public TipoRetorno metodoDos(TipoDato parametro) {
        // OBLIGATORIO: implementar el método
        return valor;
    }
}
```

## Ejemplo: CanalNotificacion

```java
// Interfaz: define el contrato "enviar una notificación"
public interface CanalNotificacion {
    void enviar(Notificacion notificacion);
}

// =====================================================================//

// Implementación por Email
public class CanalEmail implements CanalNotificacion {
    @Override
    public void enviar(Notificacion notificacion) {
        System.out.println("Enviando Email...");
        System.out.println("Destinatario: " + notificacion.getDestinatario());
        System.out.println("Mensaje: " + notificacion.getMensaje());
    }
}

// Implementación por SMS
public class CanalSMS implements CanalNotificacion {
    @Override
    public void enviar(Notificacion notificacion) {
        System.out.println("Enviando SMS...");
        System.out.println("Destinatario: " + notificacion.getDestinatario());
    }
}

// Implementación por WhatsApp
public class CanalWhatsapp implements CanalNotificacion {
    @Override
    public void enviar(Notificacion notificacion) {
        System.out.println("Enviando WhatsApp...");
        System.out.println("Destinatario: " + notificacion.getDestinatario());
    }
}
```

## Ejemplo: Múltiples interfaces

```java
// Segunda interfaz
public interface RegistroNotificacion {
    void registrar(Notificacion notificacion);
}

// =====================================================================//

// Una clase puede usar la interfaz como tipo de dato en sus atributos
public class Notificador {
    private CanalNotificacion canal;         // interfaz como tipo
    private RegistroNotificacion registro;   // otra interfaz como tipo

    public Notificador(CanalNotificacion canal, RegistroNotificacion registro) {
        this.canal = canal;
        this.registro = registro;
    }

    public void procesar(Notificacion notificacion) {
        canal.enviar(notificacion); // llama al método de la interfaz
    }
}
```

## Interfaces del JDK que se usan comúnmente

```java
// Serializable: marca una clase para que pueda ser guardada en archivos
public class Producto implements Serializable {
    private String nombre;
    private double precio;
    // ...
}

// Runnable: define una tarea que puede ejecutarse en un hilo (Thread)
public class TareaCajero implements Runnable {
    @Override
    public void run() {
        // código que ejecuta el hilo
    }
}
```

## Interfaz vs Clase Abstracta

| Característica | Interfaz | Clase Abstracta |
|---|---|---|
| Instanciar | No | No |
| Atributos de instancia | No | Sí |
| Constructor | No | Sí |
| Métodos con cuerpo | Solo `default` (Java 8+) | Sí |
| Herencia múltiple | Sí (`implements A, B, C`) | No (solo `extends` una) |
| Cuándo usar | Definir un contrato/capacidad | Compartir lógica común entre hijos |

- Una clase puede implementar **varias** interfaces: `class MiClase implements InterfazA, InterfazB`
- Las interfaces promueven el **bajo acoplamiento**: puedes cambiar la implementación sin afectar al código que la usa.
- Usa interfaces cuando diferentes clases no relacionadas necesitan compartir un comportamiento común.
