# ESTRUCTURAS REPETITIVAS

Las estructuras repetitivas permiten ejecutar un bloque de sentencias tantas veces como se necesita, o tantas veces como se cumpla una condición. Las estructuras repetitivas en Java son: while, do-while, for y for-each.

## while

El bucle `while` evalúa la condición antes de ejecutar el bloque. Si la condición es falsa desde el inicio, el bloque nunca se ejecuta.

```java
// Sintaxis
while (condición) {
    // Bloque de código que se repite mientras la condición sea true
}

// Ejemplo: contador simple
int contador = 0;
while (contador < 5) {
    System.out.println("Contador: " + contador);
    contador++;
}
```

```java
// Ejemplo: menú interactivo con while (patrón común en los proyectos)
boolean continuar = true;
while (continuar) {
    System.out.println("1. Opción A");
    System.out.println("2. Salir");
    int opcion = scanner.nextInt();
    switch (opcion) {
        case 1:
            // lógica
            break;
        case 2:
            continuar = false; // Rompe el ciclo while
            break;
    }
}
```

## do-while

El bucle `do-while` ejecuta el bloque al menos una vez y luego evalúa la condición. Es útil para validar datos del usuario.

```java
// Sintaxis
do {
    // Bloque de código que se ejecuta al menos una vez
} while (condición);

// Ejemplo: validar que un dato ingresado sea positivo
double deposito;
do {
    System.out.print("Ingrese monto (debe ser mayor a 0): ");
    deposito = scanner.nextDouble();
} while (deposito <= 0);
```

```java
// Ejemplo: validar rango de nota
double nota;
do {
    System.out.print("Ingrese nota (0 a 10): ");
    nota = scanner.nextDouble();
} while (nota < 0 || nota > 10);
```

## for

El bucle `for` se usa cuando se conoce de antemano cuántas veces se va a iterar. Incluye inicialización, condición e incremento en una sola línea.

```java
// Sintaxis
for (inicialización; condición; incremento) {
    // Bloque de código
}

// Ejemplo: recorrer un arreglo por índice
int[] numeros = new int[5];
for (int i = 0; i < numeros.length; i++) {
    System.out.println("Elemento " + i + ": " + numeros[i]);
}
```

```java
// Ejemplo: mostrar catálogo con índice
for (int i = 0; i < catalogo.length; i++) {
    System.out.println((i + 1) + ". " + catalogo[i].getNombre());
}
```

## for-each (for mejorado)

El bucle `for-each` se usa para recorrer colecciones o arreglos sin necesidad de manejar índices. Es más limpio y legible.

```java
// Sintaxis
for (TipoDato variable : coleccionOArreglo) {
    // Bloque de código
}

// Ejemplo: recorrer una lista de estudiantes
List<Estudiante> estudiantes = new ArrayList<>();
for (Estudiante est : estudiantes) {
    System.out.println("Estudiante: " + est.getNombre());
}
```

```java
// Ejemplo: recorrer un Set de ciudades
Set<String> ciudades = new HashSet<>();
for (String c : ciudades) {
    System.out.print(c + " ");
}

// Ejemplo: recorrer un Map con entrySet
Map<String, Integer> mapa = new HashMap<>();
for (Map.Entry<String, Integer> entry : mapa.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}
```

- `while` → cuando no sabes cuántas veces se repetirá.
- `do-while` → cuando necesitas que se ejecute al menos una vez (validaciones).
- `for` → cuando sabes cuántas iteraciones necesitas.
- `for-each` → cuando solo necesitas recorrer una colección completa sin índice.
