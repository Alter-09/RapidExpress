# HASHMAP Y COLECCIONES MAP

Un `HashMap` es una estructura de datos que almacena pares **clave-valor**. Cada clave es única y se asocia a un valor. Es extremadamente rápido para buscar, insertar y eliminar por clave. No mantiene un orden específico.

## Declaración e inicialización

```java
import java.util.HashMap;
import java.util.Map;

// Declarar usando la interfaz Map (recomendado)
Map<TipoClave, TipoValor> nombreMapa = new HashMap<>();

// Ejemplos
Map<String, Double> notas = new HashMap<>();         // clave: ID, valor: nota
Map<String, Integer> vuelosPorDestino = new HashMap<>(); // clave: ciudad, valor: cantidad
```

## Métodos principales

```java
Map<String, Double> notas = new HashMap<>();

// Agregar o actualizar un par clave-valor
notas.put("123", 8.5);     // agrega "123" -> 8.5
notas.put("123", 9.0);     // actualiza "123" -> 9.0 (la clave ya existía)

// Obtener un valor por clave
Double nota = notas.get("123");         // devuelve 9.0
Double notaDefault = notas.getOrDefault("999", 0.0); // devuelve 0.0 si no existe

// Verificar si una clave existe
boolean existe = notas.containsKey("123"); // true

// Obtener el tamaño
int tamaño = notas.size();

// Eliminar por clave
notas.remove("123");
```

## Recorrer un HashMap

```java
Map<String, Integer> mapa = new HashMap<>();

// Recorrer con entrySet() (clave y valor)
for (Map.Entry<String, Integer> entry : mapa.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

// Recorrer solo las claves
for (String clave : mapa.keySet()) {
    System.out.println(clave);
}

// Recorrer solo los valores
for (Integer valor : mapa.values()) {
    System.out.println(valor);
}
```

## Ejemplo: Contador de vuelos por destino

```java
// Contar cuántos vuelos van a cada ciudad
public Map<String, Integer> getVuelosPorDestino() {
    Map<String, Integer> mapa = new HashMap<>();
    for (Vuelo v : vuelos.obtenerTodos()) {
        String ciudad = v.getDestino().getCiudad();
        mapa.put(ciudad, mapa.getOrDefault(ciudad, 0) + 1); // si no existe, empieza en 0
    }
    return mapa;
}

// Mostrar resultados
for (Map.Entry<String, Integer> entry : mapa.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue() + " vuelos");
}
```

- `HashMap` no garantiza orden. Si necesitas orden de inserción, usa `LinkedHashMap`.
- Las claves deben ser únicas; si repites una clave, el valor anterior se sobreescribe.
- `getOrDefault(clave, valorDefault)` es muy útil para contadores y evitar `NullPointerException`.
- Las claves pueden ser `String`, `Integer`, o cualquier objeto que implemente `hashCode()` y `equals()`.
