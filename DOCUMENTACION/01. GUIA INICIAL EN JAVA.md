## OPERADORES DE ASIGNACION ARITMETICOS

Los operadores aritméticos en Java son los operadores que permiten realizar operaciones matemáticas: suma, resta, multiplicación, división y resto.

```java
 + // suma
 - // resta
 * // multiplicacion
 / // division
 % // modulo
 ++ // incremento
 -- // decremento

double v1 = 5;
double v2 = 2; 
double suma = v1 + v2; //7 
double resta = v1 - v2; //3 
double multiplicacion = v1 * v2; //10 
double division = v1/v2; //2.5 
double resto = v1%v2; //1 
```

En todos los casos el valor de la variable acabará con una unidad más (para el operador de incremento) o con una unidad menos (para el operador de decremento). En el caso de utilizarlo como prefijo el valor de asignación será el valor del operando más el incremento de la unidad. Y si lo utilizamos como sufijo se asignará el valor del operador y luego se incrementará la unidad sobre el operando. A continuación, se muestra un ejemplo de a que es equivalente a cada una de las convenciones (como sufijo o como prefijo). 

```java
incremento = ++v1;
// Equivalente a 
v1 = v1 + 1; 
incremento = v1;

incremento = v1++; 
// Equivalente a 
incremento = v1; 
v1 = v1 + 1;
```

