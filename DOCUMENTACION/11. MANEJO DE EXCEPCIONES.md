# MANEJO DE EXCEPCIONES

Las excepciones son errores que ocurren durante la ejecución del programa. Java proporciona un mecanismo para capturar y manejar estos errores con `try-catch-finally`, evitando que el programa se cierre inesperadamente. También puedes crear tus propias excepciones personalizadas.

## try-catch

```java
// Sintaxis básica
try {
    // Código que puede fallar
} catch (TipoDeExcepcion e) {
    // Código que se ejecuta si ocurre esa excepción
    System.out.println("Error: " + e.getMessage());
}
```

```java
// Ejemplo: capturar error de formato de número
try {
    int numero = Integer.parseInt(texto);
} catch (NumberFormatException e) {
    System.out.println("El texto no es un número válido");
}
```

## try-catch con múltiples catch

Se pueden capturar diferentes tipos de excepciones. El orden importa: las más específicas van primero.

```java
try {
    // Código que puede lanzar distintos tipos de error
    double nota = sc.nextDouble();
    if (nota < 0 || nota > 10) {
        throw new NotaInvalidaException("La nota debe estar entre cero y diez");
    }
} catch (NotaInvalidaException e) {
    System.out.println("Error: " + e.getMessage()); // excepción específica primero
} catch (InputMismatchException e) {
    System.out.println("Error: Se esperaba un número válido");
} catch (Exception e) {
    System.out.println("Error general: " + e.getMessage()); // la más general al final
}
```

## finally

El bloque `finally` se ejecuta **siempre**, haya o no excepción. Se usa para liberar recursos (cerrar Scanner, conexiones, etc.).

```java
Scanner sc = new Scanner(System.in);
try {
    // lógica del programa
} catch (Exception e) {
    System.out.println("Error: " + e.getMessage());
} finally {
    sc.close(); // siempre se ejecuta
    System.out.println("Programa finalizado");
}
```

## throw (lanzar una excepción)

La palabra `throw` se usa para lanzar una excepción manualmente cuando se detecta una condición inválida.

```java
public void registrarPasajero(String documento, String nombre, int edad) {
    if (buscarPasajero(documento) != null) {
        throw new IllegalArgumentException("Ya existe un pasajero con ese documento.");
    }
    if (edad <= 0) {
        throw new IllegalArgumentException("La edad debe ser mayor que 0.");
    }
    // lógica de registro...
}
```

## throws (declarar que un método puede lanzar excepciones)

La palabra `throws` en la firma del método avisa que ese método puede lanzar una excepción y que quien lo llame debe manejarla.

```java
// El método declara que puede lanzar VueloLlenoException
public void reservarVuelo(String documento, String codigoVuelo) throws VueloLlenoException {
    if (!vuelo.tieneCupo()) {
        throw new VueloLlenoException("No existen asientos disponibles.");
    }
    // lógica de reserva...
}

// =====================================================================//

// Quien llama al método debe manejar la excepción
try {
    sistema.reservarVuelo("1001", "AV101");
} catch (VueloLlenoException e) {
    System.out.println(e.getMessage());
} catch (IllegalArgumentException e) {
    System.out.println(e.getMessage());
}
```

## Crear excepciones personalizadas

```java
// Excepción personalizada: hereda de Exception
public class VueloLlenoException extends Exception {
    public VueloLlenoException(String mensaje) {
        super(mensaje); // pasa el mensaje al constructor de Exception
    }
}

// =====================================================================//

public class NotaInvalidaException extends Exception {
    public NotaInvalidaException(String mensaje) {
        super(mensaje);
    }
}
```

## Capturar múltiples excepciones en un solo catch

```java
// Con el operador | se capturan varias excepciones en un solo bloque
try {
    // código
} catch (IOException | ClassNotFoundException e) {
    System.out.println("Error: " + e.getMessage());
}
```

- `try` → envuelve el código que puede fallar.
- `catch` → captura y maneja la excepción. Pueden ser múltiples (del más específico al más general).
- `finally` → se ejecuta siempre, ideal para cerrar recursos.
- `throw` → lanza una excepción manualmente.
- `throws` → declara en la firma del método que puede lanzar una excepción.
- `extends Exception` → para crear excepciones personalizadas (checked).
- `extends RuntimeException` → para crear excepciones no verificadas (unchecked, como `IllegalArgumentException`).
