# HASHSET TREESET Y COLECCIONES SET

Un `Set` es una colección que **no permite elementos duplicados**. A diferencia de una `List`, un `Set` no tiene índices y no garantiza un orden específico (depende de la implementación). Las implementaciones más comunes son `HashSet` (sin orden) y `TreeSet` (ordenado).

## HashSet

`HashSet` almacena elementos únicos sin un orden garantizado. Es la implementación más rápida de `Set`.

```java
import java.util.HashSet;
import java.util.Set;

// Declarar usando la interfaz Set (recomendado)
Set<TipoDato> nombreSet = new HashSet<>();

// Ejemplo
Set<String> ciudades = new HashSet<>();
```

## Métodos principales

```java
Set<String> ciudades = new HashSet<>();

// Agregar elementos
ciudades.add("Bogotá");
ciudades.add("Medellín");
ciudades.add("Bogotá"); // NO se agrega (duplicado), el Set lo ignora

// Tamaño
int tamaño = ciudades.size(); // 2 (no 3, porque "Bogotá" no se repitió)

// Verificar si contiene un elemento
boolean existe = ciudades.contains("Cali"); // false

// Eliminar
ciudades.remove("Medellín");

// Recorrer
for (String c : ciudades) {
    System.out.print(c + " ");
}
```

## Ejemplo: Obtener ciudades destino únicas

```java
// Recolectar todas las ciudades destino sin repetir
public Set<String> getCiudadesDestino() {
    Set<String> ciudades = new HashSet<>();
    for (Vuelo v : vuelos.obtenerTodos()) {
        ciudades.add(v.getDestino().getCiudad()); // si ya existe, no la agrega
    }
    return ciudades;
}

// Mostrar
Set<String> destinos = getCiudadesDestino();
for (String d : destinos) {
    System.out.print(d + " ");
}
```

## TreeSet

`TreeSet` almacena elementos únicos **ordenados automáticamente** (orden natural o con un `Comparator` personalizado).

```java
import java.util.TreeSet;
import java.util.Comparator;

// TreeSet con orden natural (alfabético para String, numérico para Integer)
Set<String> nombres = new TreeSet<>();
nombres.add("Carlos");
nombres.add("Ana");
nombres.add("Beto");
// Al recorrer: Ana, Beto, Carlos (orden alfabético automático)

// TreeSet con Comparator personalizado
Set<Estudiante> estudiantes = new TreeSet<>(Comparator.comparing(Estudiante::getNombre));
// Los estudiantes se ordenan alfabéticamente por nombre al insertarlos
```

## Ejemplo: Estudiantes ordenados por nombre

```java
// Crear TreeSet con Comparator que ordena por nombre
Set<Estudiante> estudiantes = new TreeSet<>(Comparator.comparing(Estudiante::getNombre));

// Agregar estudiantes (se ordenan automáticamente)
estudiantes.add(new Estudiante("Fabio", "123", NivelCurso.BASICO));
estudiantes.add(new Estudiante("JSON", "457", NivelCurso.AVANZADO));
estudiantes.add(new Estudiante("Jhon", "789", NivelCurso.INTERMEDIO));

// Al recorrer, salen ordenados: Fabio, Jhon, JSON
for (Estudiante e : estudiantes) {
    System.out.println(e);
}
```

## HashSet vs TreeSet

| Característica | HashSet | TreeSet |
|---|---|---|
| Duplicados | No | No |
| Orden | Sin orden garantizado | Ordenado (natural o Comparator) |
| Velocidad | Más rápido (O(1)) | Más lento (O(log n)) |
| Cuándo usar | Solo necesitas unicidad | Necesitas unicidad + orden |

- Los `Set` son ideales cuando necesitas **elementos únicos** (ej. ciudades sin repetir, IDs únicos).
- `HashSet` → rápido, sin orden. Ideal para verificar existencia.
- `TreeSet` → ordenado automáticamente. Ideal para listados alfabéticos o numéricos.
- Para que `TreeSet` funcione, los elementos deben ser `Comparable` o se debe pasar un `Comparator`.
