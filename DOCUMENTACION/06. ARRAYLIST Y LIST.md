# ARRAYLIST Y LIST

`ArrayList` es la implementación más usada de la interfaz `List`. Permite almacenar una colección de objetos que puede crecer dinámicamente (a diferencia de los arreglos que tienen tamaño fijo). Los elementos se almacenan en orden de inserción y se acceden por índice.

## Declaración e inicialización

```java
// Importar
import java.util.ArrayList;
import java.util.List;

// Declarar usando la interfaz List (recomendado)
List<TipoDato> nombreLista = new ArrayList<>();

// Declarar usando la clase directamente
ArrayList<TipoDato> nombreLista = new ArrayList<>();

// Ejemplos
List<String> nombres = new ArrayList<>();
List<Double> notas = new ArrayList<>();
List<Producto> productos = new ArrayList<>();
```

## Métodos principales

```java
List<String> lista = new ArrayList<>();

// Agregar elementos
lista.add("elemento");           // agrega al final
lista.add(0, "primero");         // agrega en posición específica

// Obtener elementos
String item = lista.get(0);     // obtiene por índice

// Tamaño
int tamaño = lista.size();      // cantidad de elementos

// Verificar si contiene un elemento
boolean existe = lista.contains("elemento"); // true o false

// Eliminar elementos
lista.remove(0);                 // elimina por índice
lista.remove("elemento");       // elimina por valor

// Limpiar toda la lista
lista.clear();
```

## Recorrer un ArrayList

```java
List<Estudiante> listaEstudiantes = new ArrayList<>();

// Con for clásico
for (int i = 0; i < listaEstudiantes.size(); i++) {
    System.out.println(listaEstudiantes.get(i).getNombre());
}

// Con for-each (más limpio y recomendado)
for (Estudiante est : listaEstudiantes) {
    System.out.println("Estudiante: " + est.getNombre());
}
```

## Ejemplo completo: Lista de objetos

```java
// Crear la lista
List<Pasajero> pasajeros = new ArrayList<>();

// Agregar objetos
pasajeros.add(new Pasajero("1001", "Laura Gómez", 25));
pasajeros.add(new Pasajero("1002", "Andrés Martínez", 32));

// Recorrer e imprimir
for (Pasajero p : pasajeros) {
    System.out.println(p.getNombre());
}

// Verificar tamaño
System.out.println("Total pasajeros: " + pasajeros.size());

// Verificar si tiene cupo
boolean tieneCupo = pasajeros.size() < capacidad;
```

## Ejemplo: Historial con límite de tamaño

```java
// Mantener solo las últimas 5 transacciones
ArrayList<String> historial = new ArrayList<>();

protected void registrarMovimiento(String movimiento) {
    historial.add(movimiento);
    if (historial.size() > 5) {
        historial.remove(0); // Elimina el más antiguo
    }
}
```

## Devolver una copia defensiva

```java
// Devolver una copia de la lista para proteger el estado interno
public List<Persona> getPersonas() {
    return new ArrayList<>(personas); // crea una nueva lista con los mismos elementos
}
```

- `ArrayList` puede almacenar cualquier tipo de objeto, pero NO tipos primitivos directamente (usa `Integer`, `Double`, etc.).
- Se recomienda declarar con `List<T>` (interfaz) y crear con `new ArrayList<>()` para mayor flexibilidad.
- El operador diamante `<>` infiere el tipo automáticamente desde Java 7.
